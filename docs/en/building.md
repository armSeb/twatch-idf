# Building, flashing and testing

[Français](../fr/building.md) · English

## Requirements

- **ESP-IDF 5.5.6** — mandatory. With ESP-IDF 5.5.3 (the version bundled with PlatformIO's
  `espressif32@6.13.0`), the ESP32 Bluetooth controller (`libbtdm 045a658`) drops the iPhone
  link with a supervision timeout (0x208) right after encryption: pairing never completes.
  The controller shipped with 5.5.6 (`919c7f4`) fixes it. Check the boot log for
  `BTDM_INIT: BT controller compile version [919c7f4]`.
- LVGL **9.2.2**, fetched by the ESP-IDF component manager (`main/idf_component.yml`).
- Python 3 and gcc for the PC tests.

## Build

```bash
idf.py build                       # ESP-IDF 5.5.6
idf.py -p /dev/ttyUSB0 flash monitor
```

or with PlatformIO (it forces ESP-IDF 5.5.6 through `platform_packages`):

```bash
pio run -t upload -t monitor
```

Options, as environment variables at build time:

| Variable | Effect |
|---|---|
| `TW_NO_TVOFF=1` | builds without the *TV off* app and its CC BY-SA 4.0 code database |
| `TW_EXTRA_COMPONENT_DIRS=/path` | extra component directory (e.g. a local LVGL copy for offline builds, with `IDF_COMPONENT_MANAGER=0`) |
| `TW_DIAG_BLE_ONLY=1`, `TW_DIAG_BARE=1` | diagnostic builds (BLE only / no peripherals) |

After **any change to `sdkconfig.defaults`**, delete the generated `sdkconfig` (keep
`sdkconfig.defaults`) and rebuild; otherwise the old values stay.

## Flash layout

| Offset | Content |
|---|---|
| `0x1000` | bootloader (with app rollback) |
| `0x8000` | partition table |
| `0x9000` | NVS (settings, pairings, battery history) |
| `0x10000` | OTA data (which slot boots) |
| `0x20000` | `ota_0` (3 MB) |
| `0x320000` | `ota_1` (3 MB) |
| `0x620000` | core dump |

## Flashing

**First install** (erases everything, pairings included):

```bash
esptool.py --chip esp32 -b 921600 write_flash 0x0 twatch2020v1-full.bin
```

**Over USB while keeping pairings and settings** (or migrating from a version without OTA):

```bash
esptool.py --chip esp32 -b 921600 write_flash \
  0x1000 bootloader.bin 0x8000 partition-table.bin \
  0x10000 ota_data_initial.bin 0x20000 twatch2020v1-app.bin
```

`ota_data_initial.bin` makes the watch boot `ota_0`, where the application is written.

**Over the air**: see the README (*Settings › Update*). The update page is served by the
watch itself at `http://192.168.4.1`; it follows the browser language (French or English)
and has a language button.

## Release binaries (CI)

`.github/workflows/build.yml` runs the PC tests and the firmware build on every push. On a
`v*` tag it publishes:

- `twatch2020v1-full.bin` — complete image for `0x0`;
- `twatch2020v1-app.bin` — application only (Wi-Fi update or USB at `0x20000`);
- `twatch2020v1-app-notvoff.bin` — same, built with `TW_NO_TVOFF=1` (no CC BY-SA content);
- `LICENSE` and `THIRD_PARTY_NOTICES.md`.

The workflow artifact also contains the bootloader, partition table, OTA data and the ELF
(for decoding crashes).

## PC tests

```bash
host_tests/run.sh
```

Runs, under AddressSanitizer and UBSan:

- the ANCS parser (10,000 random fragmentations of the Data Source stream), UTF-8 cleanup,
  notification store (dedup, sort, capacity);
- the adaptive battery gauge (simulated batteries of 150, 220 and 360 mAh, partial charges,
  counter resets);
- `check_i18n.py`: every `_()`/`N_()` string has an English translation with the same printf
  specifiers in the same order.

## Debugging

- **Crash**: the core dump is kept in flash. `esp-coredump info_corefile build/twatch.elf`.
- **BLE without a computer**: *Settings › About* shows a time-stamped BLE log (connections,
  peer address, encryption, disconnection reasons, advertising), wake-up counters, heap,
  PSRAM and power-rail registers.
- **Battery**: *Battery* screen (average current, standby share, previous discharge, learned
  capacity).

## Fonts

`main/fonts/` is generated by `tools/gen_fonts.sh` (needs
[lv_font_conv](https://github.com/lvgl/lv_font_conv) and an LVGL 9.2.2 checkout for the
Montserrat and Font Awesome sources):

```bash
LVGL_DIR=/path/to/lvgl tools/gen_fonts.sh
```

To add an icon, append its Font Awesome code point to the `font_text_16` and `font_title_20`
lines, regenerate, and define its UTF-8 sequence in `main/ui_kit.h`.
