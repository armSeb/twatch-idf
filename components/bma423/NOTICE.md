# BMA423 Sensor API

Source: Bosch Sensortec BMA423 Sensor API (v2.x, 2020), as mirrored by
[wasp-os/BMA423-Sensor-API](https://github.com/wasp-os/BMA423-Sensor-API)
(commit e65f826). Copyright (c) 2020 Bosch Sensortec GmbH, BSD-3-Clause (see
`LICENSE`).

Includes the BMA423 feature-engine configuration file (`bma423_config_file[]` in
`src/bma423.c`) that enables the step counter and wrist-wear wake-up on the sensor.

Files are unchanged; only `CMakeLists.txt` was added for ESP-IDF.
